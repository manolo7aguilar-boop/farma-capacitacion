# Módulo 1 — Familias de medicamentos

> Contenido de capacitación para personal de mostrador. No reemplaza la indicación médica ni la normativa local. Todo el contenido clínico debe revisarlo un químico farmacéutico antes de publicarse.

### División sugerida (puede cambiar)

| Parte | Enfoque | Familias |
|---|---|---|
| A | OTC de mostrador | 1–8, 14 |
| B | Infecciones, piel y otros frecuentes | 9–13, 22–24 |
| C | Crónicos (cardiovascular, diabetes, respiratorio, salud mental) | 15–21 |

Cada familia cierra con evaluación (≥80% para aprobar, igual que el Módulo 0).

## 2. Plantilla estándar por familia

Cada familia debe enseñar:

1. **Qué es / para qué se usa** — función general en 1–2 frases.
2. **Principios activos comunes** — nombres genéricos (DCI). Sin marcas locales.
3. **Cómo se toma / formas frecuentes** — tabletas, jarabe, gotas, crema, inhalador, etc.
4. **Advertencias clave en mostrador** — lo que hay que preguntar o avisar siempre.
5. **Cuándo NO recomendar / derivar** — señales de alarma, grupos de riesgo, venta con receta.
6. **Mini-caso de evaluación** — 1 situación de cliente + opciones + feedback.

### Formato de ficha (para copiar)

```md
## Familia N — Nombre
- Qué es / para qué se usa:
- Principios activos comunes (genéricos):
- Formas frecuentes:
- Advertencias clave:
- Derivar / no recomendar si:
- Mini-caso:
  - Situación:
  - Opciones: A / B / C
  - Respuesta correcta + por qué:
```
